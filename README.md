# JP Golden Pearl — Website Preview

Temporary bilingual website preview for design review.

The site is plain HTML, CSS and JavaScript. All 16 pages and their required assets are included. No build step is required.

## GitHub Pages

In the repository settings, choose **Pages → Deploy from a branch → main → /(root)**. The entry point is `index.html`. Relative links support a project-level GitHub Pages address.

The preview requests search engines not to index it. This is not access control; a published Pages site is accessible to anyone with its URL.
